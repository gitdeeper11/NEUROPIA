
Installation

From PyPI

```bash
pip install neuropia-engine
```

From Source

```bash
git clone https://gitlab.com/gitdeeper11/NEUROPIA.git
cd NEUROPIA
pip install -e .
```

Requirements

· Python >= 3.11
· PyTorch >= 2.4 (optional)
· NumPy >= 2.0 (optional)

Verify Installation

```python
from neuropia import __version__, __doi__
print(f"NEUROPIA v{__version__}")
print(f"DOI: {__doi__}")
```
